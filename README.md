# Spot a Dog

A responsive static page telling the lore of Spot the Dog. Plain HTML, CSS, and SVG, with no dependencies or build step.

Open `index.html` in a browser, or serve this directory locally:

```sh
python3 -m http.server 8000
```

Visit http://localhost:8000. To publish, upload `index.html`, `styles.css`, and `spot.svg` to any static web host.
